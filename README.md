# 🧠 Simple Quiz App

A clean and interactive **Quiz Application** built using **HTML, CSS, and JavaScript**. This project allows users to answer multiple-choice questions and receive instant feedback, making learning both engaging and fun.

## ✨ Features

- 📝 Multiple-choice quiz questions
- ✅ Instant answer selection
- 🎯 Score tracking
- 🔄 Navigate through questions
- 📊 Display final score
- 🎨 Clean and responsive user interface
- ⚡ Fast and lightweight implementation

---

## 🛠️ Technologies Used

- **HTML5** – Structure of the application
- **CSS3** – Styling and responsive design
- **JavaScript (Vanilla JS)** – Quiz logic and interactivity

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/quiz-app.git
```

### 2. Navigate to the Project Folder

```bash
cd quiz-app
```

### 3. Run the Application

Open the `index.html` file in your preferred web browser.

---

## 🎮 How to Use

1. Read the displayed question carefully.
2. Select one of the provided answer options.
3. Click the **Next** button to move to the next question.
4. After completing all questions, your final score will be displayed.
5. Restart the quiz and challenge yourself again!
